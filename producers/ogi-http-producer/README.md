
### HTTP Client

> it is a producer plug-in for Ogi
>
> this makes HTTP Requests expecting message bytes to be marshalled form of `github.com/gol-gol/golhttpclient`.`HTTPRequest` struct

#### Environment Variable Configuration

* to enable SSL Verify in HTTP Requests, set env var `OGI_HTTP_PRODUCER_SKIP_SSL` to `true`
