
### Slack Notifier

> it is a producer plug-in for Ogi
>
> this sends a Slack Notification using Bot Auth Token & Channel ID; need to be already added to required channel

#### Environment Variable Configuration

* Slack Api Token set as env `OGI_SLACK_API_TOKEN`.

* Slack Channel's Id set as `OGI_SLACK_CHANNEL_ID`.

* Timezone identifier set as env `OGI_TIMEZONE`; defaults to "Asia/Kolkata".
